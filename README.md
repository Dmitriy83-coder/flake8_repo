## 2 Установка зависимостей
pip install -r requirements.txt

## 3 Настройка переменных окружения
cp .env.example .env

## 4 Запуск тестов
Все тесты (API + UI):  pytest -v
Только API тесты:      pytest -m api -v
Только UI тесты:       pytest -m ui -v

## Примечание
- API-тесты полностью рабочие 
- UI-тесты написаны по Page Object Model, но требуют обновления локаторов из-за изменений на сайте
- В коде применены необходимые по заданию навыки: Allure, фикстуры, маркеры, работа с конфигами
